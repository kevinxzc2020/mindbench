# 首页动效补充

日期：2026-09-21。此前的改版主要完成静态视觉，本次补充交互行为。

## 参考依据

用户提供的 Nightkidz HTML（附件 99a71628-11f2-4964-850e-1a74a7d9fba9）和全局 CSS（附件 cce74b57-043a-43fd-8413-3af5d8c7ac88），以及消息中直接粘贴的 pixel_canvas / SlidingText CSS。原文件未给出发布时间；本次核对日期见上。

| 参考代码中的证据 | MindBench 实现 |
| --- | --- |
| pixel_canvas、image-rendering:pixelated | 主图 canvas 降采样像素化后恢复清晰；原图始终在底层，不需要等待画布才能看到内容 |
| data-scramble-text | 标题、分类和游戏名逐字扰码还原；辅助技术读取稳定原文，隐藏占位保持尺寸 |
| data-mouse-gallery、data-mouse-gallery-target | 首页主图区域的鼠标图片轨迹；使用现有生成主图的局部裁切，数量有上限并自动移除 |
| home-blur-overlay、backdrop-filter | 首页图片随滚动轻微位移、缩放和模糊；不拦截页面滚动 |
| SlidingText 三份字标的水平排列 | 初版的大字标横移已于 2026-09-21 按用户确认移除，改为简洁全站页脚；其他首页动效保留 |
| data-entry-motion-source | 卡片进入视口短距离上移，像素格揭示；卡片内容默认可见，无入场门禁 |

原站 JavaScript 动效实现没有随这些 CSS 一起提供。本次是与现有 Next.js 项目适配的同类效果，不声称复原原站的全部逻辑、精确轨迹或时序。没有引入商城页面过渡或强制全屏入场遮罩。

## 文件与控制

- src/components/HomeMotion.tsx：首页专用控制器、文字扰码、画布、轨迹、视口和事件清理。
- src/app/motion.css：独立动效样式；src/app/layout.tsx 载入，但只匹配首页选择器。
- src/app/page.tsx：动效结构、三语“重播特效”及“开关动效”按钮。
- 不改游戏计时、成绩或广告请求。关闭动效、减少动态效果偏好及离开首页都会取消动效并还原文字和图片。

## 验证记录

- TypeScript 与 git diff --check 通过。
- 浏览器实际点击重播时，canvas 进入 revealing，扰码副本发生变化，辅助技术标签保持原文。
- 在首页图片区移动鼠标实际出现图片轨迹；随后检查轨迹元素归零。
- 滚动后主图位移和模糊变量更新；游戏卡片和额外探索入口仍存在。
- 键盘聚焦游戏卡片时实际触发像素格和游戏名扰码，不依赖鼠标悬停。
- 修正响应式图片 srcset 的密度坐标影响，使用同一缓存 URL 的独立解码位图进行 canvas 裁切。
